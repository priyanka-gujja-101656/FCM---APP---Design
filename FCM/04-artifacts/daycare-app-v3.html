Daycare teacher app · full screen set · v3

Sunflower Room

Twelve screens in the day-arc language. Each one sits at the hour it is actually used — arrival screens at sunrise, logging at midday, pickup and messages at sunset — so the sky keeps telling the teacher where they are without a single date picker.

Scroll each row sideways.

Attendance01 – 06

Every attendance verb from the brief: check in and out, view, mark absent, relocate, bulk, print. The primary action on Today changes with the hour, so the right verb is already the biggest thing on screen.

Activities07 – 10

Twelve activity types on one screen, no scrolling. Logging sets the whole room first and corrects exceptions second — the opposite of a form per child.

Messages11 – 12

Threads named for the guardian, subtitled with the child. The teacher answers by attaching the log she already made.

One arc, one clock

Only Today carries the arc. Everywhere else the sky alone does the work, and the palette shifts with the hour the screen belongs to.

One action per screen

Exactly one terracotta element is ever live: the primary button, or the selection bar when the teacher is choosing. Never both.

Colour is meaning

Green dot is here. Amber is expected. Warm grey is away or gone home. Amber tint marks the one incident worth catching in a feed of thirty-four entries.

Bulk is a mode, not a screen

Check-in, relocate and meal logging are the same list with checkboxes. Learn it once, use it three ways.

Sheets for decisions

Check in, print and export are all three fields and a button in the same sheet shape, so a new pattern never has to be learned.

Nap protects the room

At 12:30 the palette cools to lavender-grey, contrast drops and the accent desaturates, so a bright screen never wakes a sleeping child.
